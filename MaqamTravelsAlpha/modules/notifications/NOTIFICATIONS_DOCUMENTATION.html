01 Module Overview

The Notifications Module is the centralized messaging, alerting, and transactional communication hub of the MaqamTravels platform. It handles omnichannel user engagement across travel booking lifecycles, payment states, authentication events, and administrative alerts.

Decoupled Asynchronous Dispatch

Decouples checkout and booking flows from third-party communication latency (SMTP, SendGrid, Meta WhatsApp Cloud API, Twilio, SMS gateways). API responses return in <100ms.

Meta WhatsApp Cloud API

Dispatches official HSM templates with customer name, PNR, hotel confirmation codes, and streams PDF invoices/vouchers directly into WhatsApp.

Nodemailer HTML Vouchers

Delivers responsive, branded HTML booking confirmations with passenger manifests, itineraries, and attached legal tax invoice PDFs.

Guaranteed Idempotency

Implements deduplication keys ensuring pilgrims and customers are never spammed or double-messaged during webhook retries or network reconnects.

03 System Architecture & Flow

The notifications engine follows an Asynchronous Outbox / Worker Queue Pattern to ensure API response times remain under 100ms even when external email/WhatsApp/SMS providers experience throttling or network latency.

sequenceDiagram autonumber participant Client as Client / Mobile App participant Core as Core App (Booking / Ticketing / Webhook) participant NotifSvc as Notification Service participant DB as MongoDB (NotificationLog) participant Queue as BullMQ (notification-queue) participant Worker as Background Worker participant Email as Email Provider (SMTP/SendGrid) participant WA as WhatsApp (Meta Cloud API) participant SMS as SMS Gateway (Fast2SMS / Twilio) Client->>Core: Complete Payment / Finalize Booking / Request OTP Core->>NotifSvc: enqueueNotification({ channel, eventType, recipient, ... }) NotifSvc->>DB: Create NotificationLog (status: 'queued', idempotencyKey) NotifSvc->>Queue: Enqueue notification job (jobId = idempotencyKey) NotifSvc-->>Core: Fast ACK (< 50ms) Queue->>Worker: Consume job Worker->>DB: Update status: 'processing' alt Channel == 'email' Worker->>Email: Send HTML Template + Attached PDF Email-->>Worker: SMTP Receipt / MessageID else Channel == 'whatsapp' Worker->>WA: Dispatch Meta HSM Template + Document Header (PDF) WA-->>Worker: Meta WAMID (WhatsApp Message ID) else Channel == 'sms' Worker->>SMS: Route to Fast2SMS (India) or Twilio (Intl) SMS-->>Worker: Gateway ACK / RequestID end Worker->>DB: Update status: 'sent', persist provider messageId & raw response

4.2 Unified Notification Service (notification.service.js)

Acts as the single point of entry for the entire application. Exposes domain-specific helper methods while abstracting channel selection.

JavaScript Interface modules/notifications/notification.service.js 
const NotificationLog = require('./notification.model');
const { getNotificationQueue } = require('../../workers/notifications/notification.worker');
const logger = require('../../utils/logger');

class NotificationService {
  /**
   * Generic asynchronous dispatch with idempotency protection
   */
  async enqueueNotification({
    userId = null,
    recipientEmail = null,
    recipientPhone = null,
    channel, // 'email' | 'whatsapp' | 'sms'
    eventType,
    subject = '',
    templateName = null,
    variables = [],
    messageText = '',
    mediaUrl = null,
    idempotencyKey,
  }) {
    try {
      if (idempotencyKey) {
        const existing = await NotificationLog.findOne({ idempotencyKey });
        if (existing && ['sent', 'delivered', 'queued', 'processing'].includes(existing.status)) {
          logger.info(`[Notification] Duplicate skipped for idempotencyKey: ${idempotencyKey}`);
          return existing;
        }
      }

      const logDoc = await NotificationLog.create({
        userId,
        recipient: { email: recipientEmail, phone: recipientPhone },
        channel,
        eventType,
        subject,
        templateName,
        bodyContent: messageText,
        metadata: { variables, mediaUrl },
        idempotencyKey,
        status: 'queued',
      });

      const queue = getNotificationQueue();
      if (queue) {
        await queue.add(
          'send-notification',
          { logId: logDoc._id },
          {
            jobId: idempotencyKey || String(logDoc._id),
            attempts: 3,
            backoff: { type: 'exponential', delay: 4000 },
          }
        );
      } else {
        const { processNotificationJob } = require('../../workers/notifications/notification.worker');
        setTimeout(() => processNotificationJob(logDoc._id), 50);
      }

      return logDoc;
    } catch (err) {
      logger.error(`[Notification Service] Enqueue failed: ${err.message}`);
    }
  }

  /**
   * Booking confirmed notification (Sends Email with HTML voucher + WhatsApp confirmation with PDF)
   */
  async sendBookingConfirmation({ booking, user, invoicePdfUrl = null }) {
    const bookingRef = booking.bookingReference || `BK-${booking._id}`;
    const destination = booking.details?.destination || booking.destination || 'Umrah Package';

    // 1. Email with HTML voucher + attached PDF
    if (user.email) {
      await this.enqueueNotification({
        userId: user._id,
        recipientEmail: user.email,
        channel: 'email',
        eventType: 'booking_confirmation',
        subject: `Booking Confirmed: ${bookingRef} - Maqam Travels`,
        templateName: 'booking_confirmation_email',
        variables: [user.name, bookingRef, destination, booking.details?.totalPrice || booking.totalAmount],
        mediaUrl: invoicePdfUrl,
        idempotencyKey: `notif:email:booking:${booking._id}`,
      });
    }

    // 2. WhatsApp with PDF voucher attachment
    if (user.phone) {
      await this.enqueueNotification({
        userId: user._id,
        recipientPhone: user.phone,
        channel: 'whatsapp',
        eventType: 'booking_confirmation',
        templateName: 'booking_confirmation_v1',
        variables: [user.name, bookingRef, destination],
        mediaUrl: invoicePdfUrl,
        idempotencyKey: `notif:whatsapp:booking:${booking._id}`,
      });
    }
  }

  /**
   * Flight e-ticket issued with PNR and attached PDF (Email + WhatsApp)
   */
  async sendFlightTicketed({ booking, pnr, user, eTicketPdfUrl = null }) {
    const origin = booking.origin || booking.details?.destination?.split('-')[0] || 'Origin';
    const destination = booking.destination || booking.details?.destination?.split('-')[1] || 'Destination';

    if (user.email) {
      await this.enqueueNotification({
        userId: user._id,
        recipientEmail: user.email,
        channel: 'email',
        eventType: 'ticket_issued',
        subject: `E-Ticket Issued: PNR ${pnr} (${origin} -> ${destination})`,
        templateName: 'flight_ticket_issued_email',
        variables: [user.name, pnr, `${origin} to ${destination}`],
        mediaUrl: eTicketPdfUrl,
        idempotencyKey: `notif:email:ticket:${booking._id}:${pnr}`,
      });
    }

    if (user.phone) {
      await this.enqueueNotification({
        userId: user._id,
        recipientPhone: user.phone,
        channel: 'whatsapp',
        eventType: 'ticket_issued',
        templateName: 'flight_ticket_issued',
        variables: [user.name, pnr, `${origin} to ${destination}`],
        mediaUrl: eTicketPdfUrl,
        idempotencyKey: `notif:whatsapp:ticket:${booking._id}:${pnr}`,
      });
    }
  }

  /**
   * One-time password (OTP) delivery for mobile authentication
   */
  async sendOtp(phone, otpCode) {
    return await this.enqueueNotification({
      recipientPhone: phone,
      channel: 'sms',
      eventType: 'otp_verification',
      messageText: `Your Maqam Travels verification code is ${otpCode}. Valid for 5 minutes. Do not share this code.`,
      variables: [otpCode],
      idempotencyKey: `notif:sms:otp:${phone}:${Date.now()}`,
    });
  }
}

module.exports = new NotificationService();

4.3 Email Sub-service (email/emailService.js)

Specialized for rich HTML emails, branded layouts, and transactional attachments (PDF invoices, vouchers).

JavaScript modules/notifications/email/emailService.js 
const nodemailer = require('nodemailer');
const axios = require('axios');
const logger = require('../../../utils/logger');

let transporter = null;

const getTransporter = () => {
  if (!transporter) {
    transporter = nodemailer.createTransport({
      host: process.env.SMTP_HOST || 'smtp.hostinger.com',
      port: Number(process.env.SMTP_PORT) || 465,
      secure: process.env.SMTP_SECURE === 'true',
      auth: {
        user: process.env.SMTP_USER,
        pass: process.env.SMTP_PASS,
      },
      pool: true,
      maxConnections: 5,
      maxMessages: 100,
    });
  }
  return transporter;
};

const sendEmail = async ({ to, subject, htmlBody, attachments = [], mediaUrl = null }) => {
  const mailer = getTransporter();
  const mailAttachments = [...attachments];

  // Dynamically stream PDF from remote storage (e.g. Cloudinary) into email attachment
  if (mediaUrl) {
    try {
      const response = await axios.get(mediaUrl, { responseType: 'arraybuffer' });
      mailAttachments.push({
        filename: 'MaqamTravels_Document.pdf',
        content: Buffer.from(response.data),
        contentType: 'application/pdf',
      });
    } catch (err) {
      logger.warn(`[Email Service] Failed to stream attachment from URL: ${mediaUrl} - ${err.message}`);
    }
  }

  const mailOptions = {
    from: `"${process.env.EMAIL_FROM_NAME || 'Maqam Travels'}" <${process.env.EMAIL_FROM_ADDRESS || process.env.SMTP_USER}>`,
    to,
    subject,
    html: htmlBody,
    attachments: mailAttachments,
  };

  const info = await mailer.sendMail(mailOptions);
  logger.info(`[Email Service] Sent email to ${to} (MsgID: ${info.messageId})`);
  return { success: true, provider: 'nodemailer', messageId: info.messageId, data: info };
};

module.exports = { sendEmail };

4.4 SMS Sub-service (sms/smsService.js)

Specialized for critical, high-urgency notifications (OTPs, flight gate changes, instant payment confirmations).

JavaScript modules/notifications/sms/smsService.js 
const axios = require('axios');
const logger = require('../../../utils/logger');
const fast2smsService = require('../../../services/fast2sms.service');

const parsePhoneNumber = (phone) => {
  const clean = String(phone).replace(/[^\d+]/g, '');
  const isIndian = clean.startsWith('+91') || (clean.length === 10 && !clean.startsWith('+'));
  const digitsOnly = clean.replace(/^\+/, '');
  return { isIndian, clean, digitsOnly };
};

const sendSMS = async ({ phone, message, variables }) => {
  const { isIndian, digitsOnly, clean } = parsePhoneNumber(phone);

  // 1. Indian Mobile Numbers -> Fast2SMS DLT route
  if (isIndian) {
    const mobile10Digits = digitsOnly.slice(-10);
    return await fast2smsService.sendOtpSMS(mobile10Digits, variables || message);
  }

  // 2. International Mobile Numbers (KSA, UAE) -> Twilio Gateway
  if (process.env.TWILIO_ACCOUNT_SID && process.env.TWILIO_AUTH_TOKEN) {
    const url = `https://api.twilio.com/2010-04-01/Accounts/${process.env.TWILIO_ACCOUNT_SID}/Messages.json`;
    const params = new URLSearchParams();
    params.append('To', clean.startsWith('+') ? clean : `+${clean}`);
    params.append('From', process.env.TWILIO_PHONE_NUMBER);
    params.append('Body', message);

    const auth = Buffer.from(`${process.env.TWILIO_ACCOUNT_SID}:${process.env.TWILIO_AUTH_TOKEN}`).toString('base64');
    const response = await axios.post(url, params, {
      headers: {
        Authorization: `Basic ${auth}`,
        'Content-Type': 'application/x-www-form-urlencoded',
      },
    });

    return {
      success: true,
      provider: 'twilio',
      messageId: response.data.sid,
      data: response.data,
    };
  }

  logger.warn(`[SMS] No international provider configured. Target: ${phone}`);
  return { success: true, provider: 'mock', messageId: `mock_${Date.now()}` };
};

module.exports = { sendSMS };

4.5 WhatsApp Sub-service (whatsapp/whatsapp.service.js)

Direct integration with the Meta WhatsApp Cloud API (Graph API v19.0). Delivers approved HSM templates, dynamic parameters, and PDF document headers.

WhatsApp Cloud API modules/notifications/whatsapp/whatsapp.service.js 
const axios = require('axios');
const logger = require('../../../utils/logger');

const GRAPH_API_VERSION = 'v19.0';

/**
 * Dispatches an approved WhatsApp Template message via Meta Cloud API
 *
 * @param {string} to - Recipient number with country code (e.g. '919876543210' or '966501234567')
 * @param {string} templateName - Approved template slug (e.g. 'booking_confirmation_v1')
 * @param {string} languageCode - e.g. 'en', 'ar'
 * @param {Array} bodyVariables - List of values replacing {{1}}, {{2}} in template
 * @param {string} mediaUrl - Optional PDF/image link to attach as Document Header
 */
const sendWhatsAppTemplate = async ({
  to,
  templateName,
  languageCode = 'en',
  bodyVariables = [],
  mediaUrl = null,
}) => {
  const phoneNumberId = process.env.WHATSAPP_PHONE_NUMBER_ID;
  const accessToken = process.env.WHATSAPP_ACCESS_TOKEN;

  if (!phoneNumberId || !accessToken) {
    logger.warn(`[WhatsApp] Meta credentials not set. Mock dispatch to ${to} for template: ${templateName}`);
    return { success: true, provider: 'mock', messageId: `wa_mock_${Date.now()}` };
  }

  // Recipient phone must be plain digits without '+'
  const recipient = String(to).replace(/[^\d]/g, '');

  const components = [];

  // Header Component: Stream PDF Document if available
  if (mediaUrl) {
    components.push({
      type: 'header',
      parameters: [
        {
          type: 'document',
          document: {
            link: mediaUrl,
            filename: 'MaqamTravels_Booking.pdf',
          },
        },
      ],
    });
  }

  // Body Component: Dynamic Variables {{1}}, {{2}}, etc.
  if (bodyVariables && bodyVariables.length > 0) {
    components.push({
      type: 'body',
      parameters: bodyVariables.map((val) => ({
        type: 'text',
        text: String(val),
      })),
    });
  }

  const payload = {
    messaging_product: 'whatsapp',
    recipient_type: 'individual',
    to: recipient,
    type: 'template',
    template: {
      name: templateName,
      language: { code: languageCode },
      components,
    },
  };

  try {
    const url = `https://graph.facebook.com/${GRAPH_API_VERSION}/${phoneNumberId}/messages`;
    const response = await axios.post(url, payload, {
      headers: {
        Authorization: `Bearer ${accessToken}`,
        'Content-Type': 'application/json',
      },
    });

    const messageId = response.data?.messages?.[0]?.id;
    logger.info(`[WhatsApp] Dispatched template ${templateName} to ${recipient} (WAMID: ${messageId})`);

    return {
      success: true,
      provider: 'meta_whatsapp',
      messageId,
      data: response.data,
    };
  } catch (error) {
    const errorDetails = error.response?.data?.error || error.message;
    logger.error(`[WhatsApp] Dispatch failed for ${recipient}: ${JSON.stringify(errorDetails)}`);
    throw new Error(typeof errorDetails === 'object' ? errorDetails.message : errorDetails);
  }
};

module.exports = { sendWhatsAppTemplate };

    idempotencyKey: `crm:resend:${channel}:${booking._id}:${Date.now()}`,
  });

  res.json({ success: true, message: `Notification queued for delivery via ${channel}` });
});

7.1 Idempotency Key Format

To avoid duplicate emails, WhatsApp messages, or SMS when payment webhooks retry or user submits requests twice:

Formula: idempotencyKey = eventType : channel : entityId : statusOrTimestamp

Examples:
• notif:whatsapp:booking:64f8e5d32b1a4c9f12345678:CONFIRMED
• notif:email:ticket:64f8e5d32b1a4c9f12345678:PNR789

7.2 BullMQ Background Worker Implementation

BullMQ Worker workers/notifications/notification.worker.js 
const { Queue, Worker } = require('bullmq');
const redisClient = require('../../utils/redis');
const NotificationLog = require('../../modules/notifications/notification.model');
const { sendEmail } = require('../../modules/notifications/email/emailService');
const { sendSMS } = require('../../modules/notifications/sms/smsService');
const { sendWhatsAppTemplate } = require('../../modules/notifications/whatsapp/whatsapp.service');
const logger = require('../../utils/logger');

const QUEUE_NAME = 'notification-dispatch-queue';
let notificationQueue = null;

const getNotificationQueue = () => {
  if (!notificationQueue && redisClient.status === 'ready') {
    notificationQueue = new Queue(QUEUE_NAME, { connection: redisClient });
  }
  return notificationQueue;
};

const processNotificationJob = async (logId) => {
  const record = await NotificationLog.findById(logId);
  if (!record || record.status === 'sent') return;

  record.status = 'processing';
  record.attempts += 1;
  await record.save();

  try {
    let result;

    if (record.channel === 'email') {
      result = await sendEmail({
        to: record.recipient.email,
        subject: record.subject,
        htmlBody: record.bodyContent,
        mediaUrl: record.metadata?.mediaUrl,
      });
    } else if (record.channel === 'whatsapp') {
      result = await sendWhatsAppTemplate({
        to: record.recipient.phone,
        templateName: record.templateName,
        bodyVariables: record.metadata?.variables || [],
        mediaUrl: record.metadata?.mediaUrl || null,
      });
    } else if (record.channel === 'sms') {
      result = await sendSMS({
        phone: record.recipient.phone,
        message: record.bodyContent,
        variables: record.metadata?.variables?.[0] || '',
      });
    }

    record.status = 'sent';
    record.provider = {
      name: result.provider,
      messageId: result.messageId,
      response: result.data,
    };
    await record.save();
  } catch (err) {
    record.status = record.attempts >= 3 ? 'failed' : 'queued';
    record.lastError = err.message;
    await record.save();
    throw err;
  }
};

const initWorker = () => {
  if (!redisClient) return null;
  return new Worker(QUEUE_NAME, async (job) => {
    await processNotificationJob(job.data.logId);
  }, { connection: redisClient, concurrency: 5 });
};

module.exports = { getNotificationQueue, processNotificationJob, initWorker };

09 Developer Implementation Roadmap

Follow this checklist to activate the notification engine across the application:

Step 1 — Data Model (notification.model.js)
Persist NotificationLog Mongoose schema with whatsapp, email, and sms channel enum and unique idempotencyKey index.
Step 2 — WhatsApp Service (whatsapp/whatsapp.service.js)
Integrate Meta WhatsApp Cloud API with HSM template validation, dynamic parameters, and remote PDF document streaming.
Step 3 — Email Transport (email/emailService.js)
Initialize Nodemailer transporter with connection pooling. Add HTML voucher rendering and remote Cloudinary PDF attachment piping.
Step 4 — SMS Regional Routing (sms/smsService.js)
Normalize phone numbers into E.164 and route Indian domestic numbers to Fast2SMS DLT and international numbers to Twilio.
Step 5 — Worker Hookup (workers/notifications/notification.worker.js)
Register BullMQ notification worker in workers/index.js with concurrency of 5 and automatic exponential backoff.
Step 6 — Wire Application Touchpoints
Connect notification.service.js into modules/auth/auth.service.js (OTP), bookingSync.js (Packages), flight-ticket-gds.worker.js (Flights), hotel-book.worker.js (Hotels), and CRM routes.
