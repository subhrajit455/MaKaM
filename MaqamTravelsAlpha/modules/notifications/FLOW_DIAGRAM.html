01 Architecture Overview

The Notifications Module implements a Single-Function Calling Paradigm. Any application domain (checkout, auth OTP, flight ticketing, hotel booking, payment webhooks, or CRM admin desk) invokes one unified function: notificationService.sendNotification(options).

The service internally coordinates channel capabilities, resolves valid delivery methods (Email, WhatsApp, SMS), guarantees deduplication via namespaced idempotency keys (${idempotencyKey}:${channel}), and hands off work asynchronously to BullMQ queue workers.

06 Single-Call Code API Example

How any application controller, checkout handler, or worker uses this single function in practice:

Example: Single Omnichannel Notification Invocation 
const notificationService = require('./modules/notifications/notification.service');

// ONE SINGLE CALL triggers Email, WhatsApp, and SMS simultaneously:
const result = await notificationService.sendNotification({
  userId: customer._id,
  recipient: {
    email: customer.email,
    phone: customer.phone,
  },
  channels: ['email', 'whatsapp', 'sms'], // Or omit / 'all' to auto-detect
  eventType: 'booking_confirmation',
  subject: `Booking Confirmed: ${booking.bookingReference} - Maqam Travels`,
  templateName: 'booking_confirmation_v1',
  variables: [
    customer.name, 
    booking.bookingReference, 
    booking.destination, 
    booking.totalAmount
  ],
  messageText: `Dear ${customer.name}, your booking ${booking.bookingReference} is confirmed!`,
  mediaUrl: booking.invoicePdfUrl, // Streams PDF e-voucher / invoice
  idempotencyKey: `booking:${booking._id}:confirm`,
});

console.log(result);
// Output:
// {
//   success: true,
//   eventType: 'booking_confirmation',
//   dispatchedChannels: ['email', 'whatsapp', 'sms'],
//   results: {
//     email: { channel: 'email', success: true, status: 'queued', logId: '66e1...' },
//     whatsapp: { channel: 'whatsapp', success: true, status: 'queued', logId: '66e2...' },
//     sms: { channel: 'sms', success: true, status: 'queued', logId: '66e3...' }
//   }
// }
