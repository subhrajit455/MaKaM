Customer Profile Management API

Complete reference for customer self-service profile updates, deactivation, and session revocation in Maqam Travels.

Base: /api/v1/auth Swagger: /api/docs/ Security: Bearer JWT Target Role: customer
PATCH PUT /api/v1/auth/me

1. Update Customer Profile

Updates personal profile details for the authenticated customer. Email and phone uniqueness are strictly enforced against other accounts.

Security Boundary: Customers can only update firstName, lastName, email, phone, and avatar. Protected fields such as role, hotelId, and isActive are ignored.

Request Headers

HeaderTypeRequiredDescription
AuthorizationStringYesBearer <access_token>
Content-TypeStringYesapplication/json

Request Body (JSON)

{
  "firstName": "Tariq",
  "lastName": "Al-Rahman",
  "email": "tariq.updated@maqamtravels.com",
  "phone": "9876543210",
  "avatar": "https://cdn-icons-png.flaticon.com/512/1077/1077114.png"
}

DELETE /api/v1/auth/me

2. Delete / Deactivate Customer Profile

Terminates the user's active session, clears authentication cookies, and deactivates the profile.

Soft Delete by Default: Sets isActive = false so historical bookings, e-tickets, and invoices remain intact. Set ?permanent=true if you wish to physically wipe the database record.

Query Parameters

ParameterTypeDefaultDescription
permanent Boolean false If true, permanently removes the record from MongoDB.

Response: 200 OK (Soft-Delete)

{
  "success": true,
  "message": "Account deactivated successfully",
  "data": {
    "id": "67d68a9fc2ba9424de376d0e",
    "deleted": true,
    "permanent": false,
    "message": "Account deactivated successfully"
  }
}
GET /api/v1/auth/me
