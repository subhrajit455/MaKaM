Package Module — Tour Guide Integration Guide

Comprehensive architectural and API guide detailing how tour guide options attach to packages. Covers admin configuration at creation time, user self-booking with interactive frontend checkboxes, and direct CRM booking for customers.

01 Executive Summary

In Maqam Travels, packages bundle core inventory items like Flights (TicketStock) and Hotels (HotelStock). The Tour Guide (Instructor) portion functions as a flexible service addon designed around three distinct real-world workflows:

1. Package Creation Time

At package creation time, the admin adds guideLocation, guidePrice, and includeGuide (or guideActive). No guideId is required or needed at creation time.

2. User Self-Booking Flow

Users can preview dynamic quotes with or without a guide using the frontend checkbox. When booking is executed, guide details are omitted from the booking payload.

3. Admin Booking for Customer

When an admin books a package for a customer, the admin chooses the package chosen by the customer (packageId). Guide details are omitted; guide selection is managed directly by users during self-booking.

04 Core Services & Input Validation

Input Validation (core/package.validator.js)

The validateGuideInput(data) helper validates all incoming guide options across package creation, update, and quote calculation:

JavaScript — package.validator.js 
const validateGuideInput = (data) => {
  if (data.includeGuide !== undefined && typeof data.includeGuide !== "boolean" && data.includeGuide !== "true" && data.includeGuide !== "false") {
    throw new AppError("includeGuide must be a boolean", 400);
  }
  if (data.guideActive !== undefined && typeof data.guideActive !== "boolean" && data.guideActive !== "true" && data.guideActive !== "false") {
    throw new AppError("guideActive must be a boolean", 400);
  }
  if (data.guidePrice !== undefined && data.guidePrice !== null && data.guidePrice !== "") {
    if (isNaN(Number(data.guidePrice)) || Number(data.guidePrice) < 0) {
      throw new AppError("guidePrice must be a number >= 0", 400);
    }
  }
  if (data.guideLocation !== undefined && data.guideLocation !== null) {
    if (typeof data.guideLocation !== "string" && !Array.isArray(data.guideLocation)) {
      throw new AppError("guideLocation must be a string or an array of strings", 400);
    }
  }
};

Package Creation Service (core/package.service.js)

Inside createPackage(data, adminUserId), guide options are cleanly normalized without requiring any external guide profile lookups:

JavaScript — package.service.js 
// Normalize guide options (admin passes includeGuide or guideActive, guidePrice, guideLocation)
const isGuideEnabled =
  data.includeGuide === true ||
  data.includeGuide === "true" ||
  data.guideActive === true ||
  data.guideActive === "true";

data.guideActive = isGuideEnabled;

if (data.guidePrice !== undefined && data.guidePrice !== null && data.guidePrice !== "") {
  data.guidePrice = Number(data.guidePrice) >= 0 ? Number(data.guidePrice) : 0;
} else {
  data.guidePrice = 0;
}

if (data.guideLocation) {
  data.guideLocation = Array.isArray(data.guideLocation)
    ? data.guideLocation.join(", ")
    : String(data.guideLocation).trim();
} else if (isGuideEnabled) {
  data.guideLocation = data.destination || null;
} else {
  data.guideLocation = null;
}

07 User Quote & Frontend Checkbox

JSON

  "quantity": 1,
  "includeGuide": true
}
Checkbox Unchecked (User Neither / No Guide)

Passing includeGuide: false books standard package with no guide fee.
