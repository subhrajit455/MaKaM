POST GET /api/v1/crm/finance/overview

Calculates Gross Revenue, Pending Payment, Net Revenue, Refunds, and Transaction counts based on payment metrics for a specified date range and currency filter.

Request Parameters (Body or Query)

Field Type Required Description
startDate ISO8601 Date No Starting boundary date (e.g. 2026-01-01)
endDate ISO8601 Date No Ending boundary date (e.g. 2026-12-31)
currency String Enum No INR, USD, EUR, AED, SAR, GBP

Sample Response Payload (200 OK)

{
  "success": true,
  "message": "Finance overview retrieved successfully",
  "data": {
    "grossRevenue": 542000.50,
    "pendingPayment": 45000.00,
    "netRevenue": 517000.50,
    "refunds": 25000.00,
    "totalTransactions": 142,
    "currency": "INR"
  }
}
GET /api/v1/crm/finance/transactions

Retrieve paginated financial transactions across all platform products (flights, hotels, packages, offers, visas).

Parameter Type Default Values / Details

limitInteger20Items per page (max 100)
statusString-paid, pending, refunded, etc.
paymentMethodString-razorpay, phonepe, paypal, stripe, bank_transfer
bookingTypeString-flight, hotel, package, offer, visa
searchString-Searches transaction ID, order ID, or capture ID
sortByStringcreatedAtcreatedAt, amount, paidAt, updatedAt

GET /api/v1/crm/finance/transactions/:id

Retrieve complete details of a specific payment transaction by its MongoDB ID.

GET /api/v1/crm/finance/refunds

Retrieve all payment refund records with populated customer details and linked parent payment info.

Query Filters

Parameter Type Allowed Values
statusStringpending, processed, failed
currencyStringINR, USD, EUR, AED, SAR, GBP
bookingTypeStringflight, hotel, package, offer, visa
sortByStringrequestedAt, processedAt, amount
PATCH /api/v1/crm/finance/refunds/:refundId/status

Update refund status (e.g. from pending to processed). Automatically recalculates parent payment totals and lifecycle status.

Request Body

Field Type Required Description
statusStringYespending, processed, failed
reasonStringNoSettlement or reconciliation reason
gatewayResponseObjectNoBank / gateway acknowledgment payload

Sample Request Body

{
  "status": "processed",
  "reason": "Reconciled with bank settlement batch #4019",
  "gatewayResponse": { "arn": "987654321098" }
}
