👥 CRM Customer Intelligence & Travellers API

Comprehensive guide for customer directory, aggregated lifetime metrics (travellers count, booked offers, money spent), individual profiles, and saved travellers.

CRM Customers Lifetime Metrics Travellers Directory
GET /api/v1/crm/customers

Retrieve all customers with aggregated business metrics: name, phone, email, totalTravellers, bookedOffersCount, isActive, and totalMoneySpent.

Query Filters

Parameter Type Default Description
pageInteger1Page number
limitInteger20Items per page (max 100)
searchString-Search by firstName, lastName, phone, or email
isActiveBoolean-Filter by true/false
sortByStringcreatedAtcreatedAt, firstName, lastName, updatedAt
sortOrderStringdescasc, desc

Retrieve all saved travellers, passport details, passenger types (Adult/Child/Infant), and default preferences belonging to a specific customer.
