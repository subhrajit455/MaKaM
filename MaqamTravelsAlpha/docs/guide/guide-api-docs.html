GET /api/v1/guides List & Search Published Guides
Public ▼

Retrieves a paginated list of active, approved tour guides. Supports filtering by destination/city (e.g. Makkah, Madinah, Jeddah), spoken languages, specialization category, date availability, and sorting by rating or price.

Query Parameter Type Required Description
destination string Optional Filter by city (e.g., Makkah, Madinah, Taif, Jeddah)
category string Optional Slug of category (e.g., umrah-mutawwif, ziyarat-history)
language string Optional Guide language (e.g., Arabic, English, Urdu, Bengali)
date ISO8601 Optional Only return guides who have available slots on this specific date
page / limit number Optional Pagination controls (Default: page=1, limit=10)
cURL Request Example 
curl -X GET "https://api.maqamtravels.com/api/v1/guides?destination=Makkah&category=umrah-mutawwif&page=1&limit=10" \

POST /api/v1/guides/:id/reviews Submit Review for a Guide
Auth Required ▼

Allows an authenticated traveler who completed a tour with this guide to post a review and star rating (1 to 5). Automatically updates the guide's cumulative rating and review count.

Body Field Type Required Description
bookingId ObjectId Required Reference to the completed guide or package booking
rating number Required Rating integer between 1 and 5
comment string Required Review feedback (min 10 characters, max 1000)

POST /api/v1/guides/admin Create & Onboard New Guide Profile
Admin Only ▼

Creates a new guide record in the system. Admin uploads identity documents, assigns initial status (defaults to pending or approved), pricing tiers, and contact numbers.

Field Type Required Description
fullName string Required Full legal name of the guide
phone string Required Mobile contact with country code
city string Required Primary operating city (e.g. Makkah, Madinah)
category string Required Category key (e.g. umrah-mutawwif)
languages array Required List of languages spoken: ["Arabic", "English"]
hourlyRate number Required Standard rate per hour in SAR
status string Optional pending, approved, active (Default: approved)
cURL Request Example 
curl -X POST "https://api.maqamtravels.com/api/v1/guides/admin" \
  -H "Authorization: Bearer " \
  -H "Content-Type: application/json" \
  -d '{
    "fullName": "Muhammad Ibrahim",
    "phone": "+966501234567",
    "email": "m.ibrahim@maqam.com",

    "fullDayRate": 950,

DELETE /api/v1/guides/admin/:id Remove or Archive a Guide
Super Admin Only ▼

Safely removes a guide from the platform. If the guide has existing active bookings, the system soft-deletes the record (isDeleted: true) to preserve financial and booking audit trails.

cURL Request Example 
curl -X DELETE "https://api.maqamtravels.com/api/v1/guides/admin/66d6c900e29c123456789fff" \
  -H "Authorization: Bearer " \
  -H "Accept: application/json"
Success Response (200 OK) 
{
  "success": true,
  "message": "Guide successfully archived and removed from active operations"
}

🗄️ Database Schemas & Entity Relationships 3 Models

1. Guide Profile Entity (Mongoose: Guide)

Stores the master guide identity, qualifications, verified credentials, pricing, and operational flags.

const GuideSchema = new mongoose.Schema({
  fullName: { type: String, required: true, trim: true },
  phone: { type: String, required: true, unique: true },
  email: { type: String, lowercase: true, trim: true },
  avatar: { type: String, default: null },
  city: { type: String, enum: ['Makkah', 'Madinah', 'Jeddah', 'Taif', 'Riyadh'], required: true, index: true },
  category: { type: String, required: true, index: true },
  languages: [{ type: String }],
  bio: String,
  hourlyRate: { type: Number, required: true },
  fullDayRate: Number,
  currency: { type: String, default: 'SAR' },
  licenseNumber: String,
  status: { 
    type: String, 
    enum: ['pending', 'approved', 'active', 'suspended'], 
    default: 'approved',
    index: true 
  },
  rating: { type: Number, default: 5.0, min: 1, max: 5 },
  totalReviews: { type: Number, default: 0 },
  isDeleted: { type: Boolean, default: false }
}, { timestamps: true });
2. Guide Slot Entity (Mongoose: GuideSlot)

Stores calendar working hours and booking availability for each guide.

const GuideSlotSchema = new mongoose.Schema({
  guide: { type: mongoose.Schema.Types.ObjectId, ref: 'Guide', required: true, index: true },
  date: { type: String, required: true, index: true }, // Format: YYYY-MM-DD
  startTime: { type: String, required: true }, // e.g. "08:00"
  endTime: { type: String, required: true },   // e.g. "12:00"
  slotType: { type: String, default: 'Standard Tour' },
  price: { type: Number, required: true },
  isBooked: { type: Boolean, default: false, index: true },
  bookingId: { type: mongoose.Schema.Types.ObjectId, ref: 'Booking', default: null }
}, { timestamps: true });

GuideSlotSchema.index({ guide: 1, date: 1, isBooked: 1 });
3. Guide Review Entity (Mongoose: GuideReview)

Records authenticated customer feedback and star ratings tied to verified tour bookings.

const GuideReviewSchema = new mongoose.Schema({
  guide: { type: mongoose.Schema.Types.ObjectId, ref: 'Guide', required: true, index: true },
  user: { type: mongoose.Schema.Types.ObjectId, ref: 'User', required: true },
  booking: { type: mongoose.Schema.Types.ObjectId, ref: 'Booking', required: true },
  rating: { type: Number, required: true, min: 1, max: 5 },
  comment: { type: String, required: true, maxlength: 1000 },
  isVerified: { type: Boolean, default: true }
}, { timestamps: true });
